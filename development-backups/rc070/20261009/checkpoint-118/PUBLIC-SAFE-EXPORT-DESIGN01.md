# Public artifact projection — finite read-only contract

No exporter has been written or executed. The original eight files and original RAW-EVIDENCE-SEAL remain immutable private evidence; this projection never substitutes for their bytes or receipt_gate. A public artifact contains exactly the four UTF-8 JSON files below, with no arbitrary metadata, logs, archives, source, binaries or subdirectories. Total output is at most 2 MiB. All object keys are exact; unknown keys, duplicate JSON keys, non-finite numbers, invalid types or missing keys reject the entire public export.

Never export raw JSON bodies or log text. NOT_RUN has empty files/null seal; executed profiles require all eight distinct files, actual no-follow read/hash, within original budgets.

All digest values are literal hex, all enums fixed ASCII and all integers have schema bounds. Thus a raw field is never copied on the assumption that its name sounds safe. In-memory environment-secret matching and PEM/private-key/GitHub-token/Authorization markers are additional fail-closed checks on the final four serialized byte buffers, not a replacement for this whitelist. No environment variable values or hashes of secrets are exported. No diagnostic exception args, body, headers, URL, socket addresses, proc fields, realm values or TLS fixtures are projected. If the source object cannot prove a typed safe field, status remains BLOCKED/UNKNOWN rather than placing its raw value in an error field. Partial successful export is forbidden; output is a fresh owned directory with no-follow/nlink1/mode checks, and closes that are UNKNOWN retain the actual objects and invalidate export.
