# Requirements

## 功能概述

Finite design delta only: atomically associate each actual ordinary child with the real retained Job at CreateProcessW through PROC_THREAD_ATTRIBUTE_JOB_LIST, and execute native Git source helper calls through a separately declared bounded IO delegate. Existing six frozen manager/IO documents and original helper source stay unchanged. No implementation/native launch is authorized by this design. Native Git remains native Git, not an API-byte adapter or a publisher/VM owner.
