## 本版变化

工作区默认单聊天独占：第一次明确申请保留90秒，必须在本机核对指纹后批准。其他聊天不能抢占，也不产生新的审批记录或通知。插件是否出现在 ChatGPT 菜单中仍由 ChatGPT 控制，服务器不会隐藏它。

所有工作区页面之外也有全局审批入口。前台应用可显示审批框；后台请求更新待审批列表和托盘标记，并尝试发送不包含路径、令牌或聊天标识的系统通知。关闭弹窗不是批准。运行任务尚未结束时，撤销权限只停止新请求，工作区保留排空状态，不能直接转交给另一聊天。

新增带轮换及旧令牌重用检测的刷新会话。只有授权请求包含 `mcp offline_access` 并经过明确的离线访问提示后，才签发 Refresh Token。凭据加密保存，刷新绝不延长本机聊天权限。程序重启后需要重新批准聊天，但有效的刷新会话可保留。

## 安装与升级

关闭旧程序。保留本机原加密配置和对应系统用户的凭据存储备份；不要将备份、密码、Refresh Token 或 Client Secret 上传到聊天。先取消或确认完成旧版任务，再升级。不能通过删除配置来绕过排空/恢复警告。

Windows x64 使用 `MCP_0.4.0_x64-setup.exe`。没有商业代码签名时可能显示未知发布者，请先核对 `SHA256SUMS_v0.4.0.txt`。

Ubuntu 22.04/24.04 amd64 使用 DEB 或 AppImage，二选一。DEB 通过本地包安装器或 `sudo apt install ./MCP_0.4.0_amd64.deb` 安装；AppImage 需赋予可执行权限。应用作为普通桌面用户运行，不使用 sudo 启动应用，不关闭 WebKit/Chromium 沙箱。图形会话、系统凭据库、通知服务及相关依赖必须正常工作。

## 配置时长

在工作区的“远程会话安全”中填写并保存。默认访问令牌60分钟、刷新会话30天、聊天租约24小时、空闲释放关闭。允许范围分别为5～480分钟、1～90天、1～720小时；空闲超时为0或30～1440分钟。

这是有效期，不是强制要求 ChatGPT 每隔固定时间刷新；实际刷新请求由客户端控制。更改设置按页面说明作用于新签发令牌及新批准租约，既有刷新会话的绝对截止时间不会悄悄延长。

授权后显示的权限只允许缩减，不允许扩大。需要修改权限或转交时，先在本机撤销并处理旧任务，再从目标聊天明确申请。不要反复让被阻断的聊天请求授权。

## ChatGPT 连接设置

服务器地址使用现有的公网 `/mcp`。身份验证为 OAuth；Client ID 和 Client Secret 必须和桌面端一致。Auth URL 为同一公网 origin 的 `/oauth/authorize`，Token URL 为 `/oauth/token`。保留准确的 ChatGPT Callback URL，并在桌面端配置完全相同的 Redirect URI。

需要长期连接时，授权作用域应包含 `mcp offline_access`。这是当前应用支持的离线刷新权限，不代表启用了 OIDC；不要勾选 OIDC，不要填写不存在的动态注册地址，也不要增加 `openid profile email`。必要时在 ChatGPT 重新创建/连接该应用，让它重新获取支持刷新会话的发现文档。不要把密钥发给模型。

Nginx 必须把三个 OAuth 发现端点以及 authorize/token 转发到与 `/mcp` 相同的实际上游。升级桌面包不会自动修改远端 Nginx。修复发现路由后，未认证 MCP 请求仍必须返回401。

## 限制和故障处理

严格轮换意味着旧 Refresh Token 重用会撤销整个刷新家族及关联访问令牌。响应丢失或客户端并发刷新也可能触发这个保护并要求重新登录；本版不会为便利而复活旧令牌。

访问令牌、刷新会话、聊天租约是三个不同生命周期。持续刷新不会恢复已撤销/过期的聊天授权，关闭浏览器聊天也不是服务器能够可靠观察到的释放事件。

如果程序异常退出并遗留无法确认结束的任务，本机显示恢复警告；先检查或终止残余进程，再在本机按提示确认。不要自动重跑未知任务，不要通过新聊天绕过恢复锁。

原生自动验收使用实际安装包、真实 WebView/IPC/本地 OAuth HTTP 与合成聊天标识。它不证明真实 ChatGPT 账号在公网完成授权或按预期刷新，也不证明你的桌面通知横幅可见。系统通知还受安装身份、系统通知权限、勿扰模式和通知服务影响，托盘/应用内待审批入口保留为替代入口。真实账号双窗口及长期使用应在你自己的机器验收。本版本为预发布，不是全面安全认证。

此前 PowerShell 偶发无输出现象没有确认根因；不能将本轮独占或刷新修改冒称为它的根因修复。

## 回滚

关闭候选程序，取消或确认结束任务，在本机撤销刷新会话后恢复旧版本与升级前的兼容配置备份。保留新的加密存储文件以便排查，不要让旧版本覆写未知格式，不要删除工作区或会话历史来清除授权。
