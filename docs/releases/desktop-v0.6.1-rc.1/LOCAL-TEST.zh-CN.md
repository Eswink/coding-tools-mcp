# 0.6.1-rc.1 桌面实机测试预发布

这是桌面本地验证版本，不是整个云网关/本地 Agent 路线图的完成版。未接通的云端业务派发、Windows 原生沙箱、Hooks、受管 worktree、快照回滚不属于本包已交付能力。完整项目的发布清单和阻断状态保持不变。

## 包含的变化

Ubuntu 的远程 exec_command、异步命令与执行健康检查现在必须在宿主持有的工作区中建立 Landlock/seccomp 隔离。缺少内核能力、工作区绑定或有效本地授权时拒绝执行，不回退到无沙箱。现有任务的本地撤销/暂停规则保留：拒绝新工作，既有工作排空或由本地用户取消；重启不自动重放不确定操作。

Linux 上的 Git 状态/diff/log/show/blame 和 Harness 的 Git 辅助查询使用有界只读沙箱，禁止工作区写入和网络；外部 diff、textconv、fsmonitor 不会获得宿主权限。

Windows 包用于验证既有授权、独占会话、暂停/恢复及任务兼容性，不宣称具有操作系统级文件系统或网络沙箱。桌面旧 tty=true 仍是管道会话；库级原生 PTY 不等于桌面已接入 PTY。

## 安装条件与限制

Ubuntu 包面向 x86_64 Ubuntu 24.04 图形桌面和普通用户。内核需支持 Landlock ABI >=3、seccomp、openat2、close_range。容器、自定义内核和旧内核可能缺少能力；此时命令失败是拒绝默认行为，不要以 root 启动或关闭隔离规避。系统运行时可只读访问，工作区外写入和网络拒绝。需要网络的依赖安装、下载、Git fetch/push 不在本次隔离执行支持范围内；请在受控本地终端准备依赖后再测试。

Windows x64 需要 WebView2。GitHub Windows Server 2025 自动测试不替代 Windows 10/11 实机观察。包可能未进行 Authenticode 签名；签名状态以构建来源记录为准，不要把校验和当作代码签名。

选择独立测试项目，不要将整个主目录、系统目录或含真实密钥的目录作为工作区。外置 .git 管理目录或跨工作区 worktree 可能被只读 Git 边界拒绝。

## 先核对，再安装

从同一预发布中取得适合系统的安装包与 SHA256SUMS.txt，核对文件摘要：

```powershell
Get-FileHash .\MCP_0.6.1-rc.1_x64-setup.exe -Algorithm SHA256
```

```bash
sha256sum MCP_0.6.1-rc.1_amd64.deb
sha256sum MCP_0.6.1-rc.1_amd64.AppImage
```

与清单中同名条目逐字比较，并查看 BUILD-INFO.json 的 source_sha、source_tree、run_id 和平台范围。版本字符串本身不是源码一致性证明。校验通过后停止旧客户端，使用 NSIS、DEB 或 AppImage 正常安装/启动。测试前备份项目文件及现有配置，避免在重要项目上首次验证。

## 建议实机观察

1. 窗口正常启动；安全存储不可用时显示锁定恢复界面，不能变成明文保存。确认应用版本为 0.6.1-rc.1。
2. 用测试工作区和新会话发起授权，仅在本地桌面批准所需权限。未批准或另一会话不得执行；不要在聊天中发送密码、令牌或私钥。
3. Ubuntu 运行简单工作区脚本，核对子进程结果的 sandbox_required 与 sandbox_enforced 为 true。内置 pwd/echo 等不创建子进程的诊断不能作为沙箱证明。
4. 使用专门的临时测试文件验证工作区外读写、越界符号链接和回环网络拒绝；不要用真实私密文件做探针。Git 只读命令应正常返回，不能执行项目配置中的外部帮助程序。
5. 提交有界异步任务后断开客户端再读取结果，检查没有重复提交或重放。测试本地暂停/恢复、取消及退出/重启后的恢复提示。不要把撤销理解成已承诺任务从未执行。
6. 记录系统/内核、安装包摘要、应用版本、测试步骤、结果与脱敏日志。真实 ChatGPT 与网络拓扑表现需要由实机观察决定，本包没有声称这些验证已通过。

## 回退与反馈

停止候选客户端后替换回既有稳定版程序。保留工作区与持久授权/恢复账本；不要删除恢复锁、恢复旧授权账本或清除不确定任务来强行解锁。需要时在本地重新授权并按界面确认任务状态。此版本不修改生产 VPS、DNS、Nginx、云端凭据或 main 分支。

自动验证说明仅涵盖对应源码与安装包的 CI 结果，不是独立安全认证。完整云网关正式发布仍需完成未交付工程和另行验收。
