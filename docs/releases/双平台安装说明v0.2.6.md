# v0.2.6 · Ubuntu 与 Windows 图形桌面版

本版同时提供 Ubuntu 22.04/24.04 amd64 的 DEB、AppImage 和 Windows x64 的 NSIS EXE。三个包来自同一main提交；版本在package、npm lock、Cargo、Cargo lock和Tauri六处一致。不覆盖已经验收的Windows v0.2.4或旧标签。

## 修复
Ubuntu专用发行入口修复Python环境污染、WebKit子进程路径和包内GIO模块ABI隔离；保留真实GnuTLS模块，不关闭沙箱或证书验证。真实GUI导航/Portal会话、加密任务重启恢复均进入原生验收。Windows脚本兼容回归使用有界60秒预算与既有会话轮询，检查真实输出；保留明确短预算TIMEOUT回归与生产默认值/上限，不把宿主冷启动耗时当作功能失败，不重提命令碰绿。

## 下载和校验
公开附件：`MCP_0.2.6_amd64.deb`、`MCP_0.2.6_amd64.AppImage`、`MCP_0.2.6_x64-setup.exe`、`Ubuntu-evidence_v0.2.6.zip`、`Windows-evidence_v0.2.6.zip`、`SHA256SUMS_v0.2.6.txt`。传输名使用ASCII以避免GitHub规范化重名；证据内保留中文名称。安装前核对所下载包的SHA256与校验文件对应行。

## Ubuntu
在Ubuntu图形桌面以普通用户登录，确保D-Bus和已解锁的GNOME Keyring/Secret Service。推荐DEB：

```bash
sha256sum MCP_0.2.6_amd64.deb
sudo apt update
sudo apt install ./MCP_0.2.6_amd64.deb
coding-tools-mcp-desktop
```

也可从应用菜单打开Coding Tools MCP。AppImage：

```bash
sha256sum MCP_0.2.6_amd64.AppImage
chmod +x MCP_0.2.6_amd64.AppImage
APPIMAGE_EXTRACT_AND_RUN=1 ./MCP_0.2.6_amd64.AppImage
```

CI认证AppImage extract-and-run模式，不代表全部FUSE环境已验证。应用本身无需Node/Rust，但执行工作区命令仍需对应Python、Git和构建环境。不要sudo启动GUI。完整条件和卸载说明见Ubuntu证据内《Ubuntu安装说明v0.2.6.md》。

## Windows
在PowerShell运行 `Get-FileHash .\MCP_0.2.6_x64-setup.exe -Algorithm SHA256`，核对后退出旧应用并运行安装程序。本包未配置商业代码签名，Windows可能提示未知发布者。需要系统WebView2；真实安装、内部PE版本、载荷SHA256、窗口创建和进程持续存活由Actions验证。不是所有Windows版本/显卡/原生交互全覆盖认证。

## 升级与边界
升级前备份配置及系统账户密钥恢复材料，不上传Token、私钥或密钥环。Windows配置目录通常为 `%APPDATA%\coding-tools-mcp-desktop`，Ubuntu通常为 `~/.config/coding-tools-mcp-desktop`。不同系统的密钥环不能只靠复制加密JSON迁移。

本版保留预发布标记，供用户本机验收。已验证范围为Ubuntu22.04/24.04 amd64 X11/Xvfb和Windows x64 Actions原生安装；无ARM64、macOS、Ubuntu26.04、无桌面Server、全部Wayland/GPU/FUSE/Conda或任意动态库环境承诺。真实公网OAuth/ChatGPT长期联调仍不计入本版自动化通过证据。工作流定义不是通过证明，实际结果在Release来源及Actions回执中。
