# v0.3.2 OAuth 发现与凭据恢复修复候选

## 本轮变更及验证范围

本轮修复 MCP OAuth 发现路径、实际运行配置应用和分层诊断，并继续修复凭据表单的异步竞态。密钥写入后服务重启失败时，界面会回读实际保存的值；若回读也失败，则清空并锁定受影响字段，而不是继续展示失效密钥。重新生成过程中，对应凭据表单不继续展示旧值。共享密钥的部分保存失败不会丢弃其他未保存草稿，读取共享身份也不会覆盖私有 Client ID 草稿。

“保存失败”不必然表示配置未落盘。先查看服务运行状态与脱敏错误，按界面回读后的值核对配置，修正重启问题后再启动服务；不要根据旧值重复授权或把密钥发到公开日志。密钥轮换后，外部客户端需要同步新凭据并重新授权。

安装包、五组合原生测试和发布状态必须以对应提交的 Actions 结果及本次 Release 附件为准。本说明文件本身不代表测试通过，也不意味着此候选已经发布。下面的安装命令仅在相应附件实际生成并通过校验后使用。

## 安装与升级

提供 Ubuntu 22.04/24.04 amd64 DEB、AppImage 和 Windows x64 NSIS。先核对本 Release 的 SHA256SUMS，退出旧程序，再安装。离线保留升级前配置和对应系统用户凭据；仅复制加密配置不能替代系统凭据备份。不要把主密钥、令牌、原始配置或个人文件上传到聊天和公开仓库。降级需恢复升级前备份。

Ubuntu：`sudo apt install ./MCP_0.3.2_amd64.deb`，从应用菜单启动；或 `chmod +x MCP_0.3.2_amd64.AppImage` 后以普通用户执行。CI 的 AppImage 使用 extract-and-run，不代表全部 FUSE、Wayland 或 GPU 环境都已验证。

Windows：运行 `MCP_0.3.2_x64-setup.exe`，以普通用户启动。包未配置商业代码签名时可能提示未知发布者。不要为测试关闭 Defender、WebView2 沙箱或系统访问控制。

## 原生验收与真实 ChatGPT 的区别

本次交付必须通过 Windows 真实窗口八阶段、实际 NSIS 安装后八阶段，以及 Ubuntu 两系统两种包的安装后八阶段；结果、源码和包摘要以本 Release 附件为准，不采用 v0.3.0 的 Windows 原生延期例外。

CI 使用本机真实 OAuth/PKCE、真实 IPC、窗口点击和真实进程，但两个聊天标识是合成测试数据。真实 ChatGPT 账号授权、真实会话元数据与公网 TLS/穿透入口联调仍须在你的机器核验，不能把 CI 结果冒称真实 ChatGPT 已通过。

## 授权流程

在本机配置工作区和公网 HTTPS 入口，再让 ChatGPT 连接 MCP 并完成 OAuth。每个新聊天默认没有业务授权。只在目标聊天调用 `request_chat_authorization` 申请最小范围，随后在桌面聊天授权面板核对工作区、权限和会话指纹并批准。不要发送长期主密钥，也不要批准不能对应到自己操作的请求。

OAuth 登录与聊天批准是两层检查。默认空闲 30 分钟、绝对 8 小时；应用重启后须重新批准聊天。桌面可拒绝、撤销及切换独占模式。

## 真实客户端本地核验表

以下不是待修的本机自动化测试，而是 CI 无法代表你的账号和公网入口完成的真实客户端核验。每项记录实际结果，不预填通过。

| 场景 | 预期 | 实测 |
|---|---|---|
| 同账号新聊天 A/B，未桌面批准 | 业务读取/执行均拒绝，仅允许授权状态与申请 | 待本地核验 |
| 只批准 A | A 仅在批准范围可用，B 仍拒绝 | 待本地核验 |
| B 知道 A 的任务/会话 ID | 仍不能读取、继续或取消 A 的资源 | 待本地核验 |
| A 只读批准后申请写入、命令或自提权 | 超出授权拒绝，模型不能自行批准 | 待本地核验 |
| 撤销 A 或全部 | 后续业务调用拒绝 | 待本地核验 |
| 独占模式切换 B | A 失去后续访问，B 仅在其范围可用 | 待本地核验 |
| 重启桌面 | 按原机制保留 OAuth 凭据，两个聊天均须重新批准 | 待本地核验 |
| 缺失/冲突元数据、失效 OAuth 或错误资源 | 默认拒绝，不回退匿名或共享主密钥 | 待本地核验 |

失败时立即撤销，记录版本、操作步骤、非秘密错误码和脱敏结果；不公开令牌或原始配置。

## 信任边界

聊天标识不是密码学认证的 ChatGPT 来源；持有有效 OAuth token 的恶意客户端可能构造该元数据。执行权限不是操作系统沙箱：获准聊天在同一工作区共享实际文件。撤销阻止后续访问，不保证自动回滚或终止所有已发出的进程。旧 Actions 业务入口在缺少合格上下文时拒绝，不作为绕过通道。

本版为预发布，不是对全部用户机器或所有平台的安全认证。旧 Release 和既有包不覆盖。
