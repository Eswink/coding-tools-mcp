# v0.2.4 · 持久异步任务与任务面板合并验收版

本版为 Windows x64 预发布安装包；源码必须来自已合并的 main。不是已完成真实公网或24小时实耗压力验收的稳定版。macOS/Linux桌面安装包不在本次构建范围。

## 本版交付

四个普通 MCP/Actions 工具：start_exec_task、get_exec_task、list_exec_tasks、cancel_exec_task。提交与HTTP等待解耦；同一工作区/通道内用request_id找回结果、拒绝参数冲突，不能在连接超时后盲目重跑。

任务记录与日志加密落盘，命名空间共用系统凭据密钥并由独占锁保护。同一应用内服务重启可复用任务；应用重启只恢复记录，非终态显示interrupted，不接管或重放命令，不根据磁盘旧PID发送信号。未知旧进程必须由本地操作者核查后显式确认停止。

异步执行拥有Unix进程组或Windows Job Object；取消和超时清理受管后代。此机制不是安全沙箱，不能保证终止故意逃逸进程组的程序，也不能撤销命令已经产生的文件修改等副作用。

异步预算默认10分钟，工作区可配置至24小时；普通exec_command仍为默认30秒、最高10分钟。保存新预算后重启相应服务生效，不修改运行中的任务。

桌面任务面板按工作区和MCP/Actions通道查询、取消任务，显示增量stdout/stderr、退出码、持久化或输出不完整警告；切换选择后拒绝迟到响应。工作区仍有活动或未确认任务时，删除/迁移被阻止。

每通道最多4个活动任务、32条保留记录；终态默认保留1小时，未确认停止的任务不会为重试释放容量。每流最多保留1MiB，每次工具分页最多16KiB。应用不会主动唤醒ChatGPT。

## 安装、升级和校验

先退出旧程序，离线备份 `%APPDATA%\coding-tools-mcp-desktop` 及系统用户凭据相关恢复材料。备份可能含历史明文Secret，不得上传仓库或分享。仅复制加密JSON而丢失系统凭据密钥，不能恢复配置或任务记录；不要让旧版改写新版加密数据。

下载Release的安装包与SHA256SUMS_v8.txt，核对安装包SHA256后安装。GitHub附件采用既有ASCII传输名，中文原始文件名和证据保存在release-evidence_v8.zip内；v8表示兼容的证据格式，不是应用版本。未配置商业代码签名时，Windows可能显示未知发布者。
