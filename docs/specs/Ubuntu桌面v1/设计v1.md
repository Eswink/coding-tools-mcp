# 设计文档：Ubuntu桌面v1

## 技术方案
复用现有LinuxPlatform、系统凭据、Rust执行引擎和Svelte页面。新增Linux专用打包覆盖配置，输出DEB/AppImage；不修改共享产品函数，除非实际回归发现阻断。Ubuntu22.04构建后在22.04/24.04下载同一工件验收（FR-1至FR-7）。

## 数据模型
来源记录包含schema_version、version、source_sha、source_tree、run_id、runner_os、assets(name,size,sha256)、checks和限制。原生测试报告分别记录DEB与AppImage使用方式，不将解包启动说成FUSE启动。配置及任务继续由原生Secret Service密钥加密，不迁移用户Windows密钥（FR-6、FR-8）。

## API设计
不增加对外工具API；测试通过真实WebDriver访问已安装应用、真实Tauri IPC创建隔离工作区，再通过既有本地HTTP工具调用验证任务。所有网络测试仅访问127.0.0.1，不自动连接公网（FR-4、FR-5）。

## 设计决策
在最旧受支持LTS构建避免glibc向下不兼容。DEB补充系统凭据运行依赖，AppImage记录外部桌面服务需求。发布只允许已合并main精确SHA，新版本不覆盖旧Release（FR-1、FR-2、FR-3、FR-6、FR-8、FR-9）。

## 测试策略
静态配置和发布脚本负向测试；Windows/Linux完整Rust和严格编译；前端与日志回归；Linux原生凭据组；DEB实际安装、ELF/版本/依赖/桌面文件检查；两LTS下DEB/AppImage真实WebKit窗口与工作区/本地任务/重启恢复；发布后逐附件下载复核（FR-1至FR-10）。

## 安全与回滚
全新普通用户隔离目录；禁用公网隧道配置，不关闭WebKit沙箱。失败退出非零，publish依赖全部门禁。任何现存同tag不同SHA/摘要的Release拒绝覆盖；不删除用户配置。旧v0.2.4继续可用（FR-6、FR-7、FR-9）。

## 文档交付
Ubuntu中文安装说明记录APT、AppImage/FUSE、Secret Service、配置目录、托盘扩展和验证边界。CI模拟X11不等于所有Wayland/GPU机器的完整验收（FR-10）。

## 概述
覆盖FR-1至FR-10；新增分发和验收工具，保持产品API不变。

## 文件结构
新增 src-tauri/Ubuntu桌面v1.json、scripts/Ubuntu原生验收v1.py、scripts/Ubuntu安装验收v1.py、scripts/Ubuntu发布v1.py、scripts/Ubuntu发布回归v1.py、.github/workflows/Ubuntu桌面构建v1.yml、docs/releases/Ubuntu安装说明v0.2.5.md。共享产品函数不变；五版本文件按既有脚本同步。
