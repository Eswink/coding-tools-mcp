# 双平台发布v8设计

## 概述

沿用Tauri/Svelte运行实现。保留PR #5完整exec.rs及四项防回退检查；在test-only模块新增Windows有界会话轮询及精确输出断言，产品超时默认值和上限不变。新的双平台Actions使用Ubuntu工作流的workflow_call复用完整validate/build/native/acceptance，并行Windows NSIS构建与已有原生安装冒烟。一个聚合门禁验证两个平台来源、负例和20轮兼容命令、同端口20轮，生成6个确定性资产。发布只允许release/双平台v8且源码与main绑定，复用已有防重定向认证客户端、草稿分阶段上传和拒绝覆盖校验；匿名下载验证不携带认证头。Ubuntu帮助模块版本更新为0.2.6，历史文档及旧Windows发布流程不改。

## 技术方案

失败路径：编译/回归/原生/来源任一失败阻止合并发布；网络/上传失败只允许同SHA同摘要草稿续传；不删除历史失败、不反复重跑碰绿。构建不是字节可复现承诺；确定性只针对相同输入证据。

## 文件结构
新增双平台发布v8工作流、聚合发布和回归脚本、Windows执行预算测试辅助模块与本规格；保留exec.rs原样，通过tools/mod.rs注册新增test-only测试、Ubuntu验收版本常量及workflow_call入口。新增双平台/Ubuntu0.2.6安装说明。
