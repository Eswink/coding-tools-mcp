# v0.2.2 固定公网入口 · Windows 本地验收版

此版本面向 Windows x64。真实服务器、域名、TLS及ChatGPT授权由使用者在本地验收；不是已完成公网验收的稳定版。macOS未构建。

## 本版改动

FRP支持服务器IP/主机名与自定义完整域名分离；支持HTTP、已有本地HTTPS与https2http、压缩、连接TLS和TCP复用。MCP/Actions均使用统一公网身份，配置校验与脱敏预览可视化。传统子域名模式保留独立后缀。

Cloudflare保留Quick临时入口，提供Named固定入口；运行中地址更新同步到OAuth元数据与Actions OpenAPI，停止时不再复制旧Quick地址。固定域名需要先在Cloudflare设置Named Tunnel的公网主机名到本地端口映射。

配置快照使用AES-256-GCM加密，密钥保存在系统凭据库，不随JSON保存；旧明文有效配置自动迁移。FRPC必须读取的运行时明文配置在Windows创建时即附带当前用户独占、禁止继承的ACL，写入前回读验证；不再依赖PowerShell设置权限。

## 安装前必须留存原配置

关闭旧程序，保留 `%APPDATA%\coding-tools-mcp-desktop` 的离线备份以及原系统用户凭据备份。备份可能包含旧明文Secret，不能上传仓库或分享。

新版本迁移后，**只复制加密JSON到另一系统用户或清空凭据管理器，不能恢复配置**。加密密钥丢失时程序拒绝覆盖原文件，不会悄悄生成空工作区。降级需恢复升级前备份；不要让旧程序直接改写新加密配置。磁盘历史块、外部旧备份和同步历史不在自动清理范围。

安装包未配置商业代码签名时可能显示未知发布者；请核对Release附件校验和。首次使用穿透功能可能需要下载frpc/cloudflared，按应用内下载设置处理网络代理。

## FRP服务器IP配置

全局FRP配置填写服务器IP、控制端口及Token。工作区选择“自定义完整域名”，填写例如 `mcp.example.com`。DNS指向你的服务器；FRPS及前置HTTPS代理需匹配该域名与正确的vhost端口。

内置MCP/Actions监听是HTTP。使用服务器端HTTPS终止时，FRP代理选择HTTP；已有本地TLS服务才使用HTTPS透传；https2http必须设置有效证书和私钥路径。界面显示公网HTTPS地址不代表证书或服务器路由已配置。

## Cloudflare固定地址

选择Named Tunnel，填写该隧道Token，以及 `https://mcp.example.com` 这样的公网根地址，不要附带 `/mcp`。Cloudflare服务地址指向工作区实际HTTP端口；整站转发须包含 `/mcp`、`/.well-known/…` 和 `/oauth/…`。

ChatGPT填入复制的MCP完整地址。Quick域名本来就会变化，不适合长期固定授权；切换到Named后可能需要一次重新添加/授权，此后正常重启不应再更换域名。

## 本地重点验收

先新建工作区保存FRP自定义域名，检查重启后配置与域名保持；再测试Named两次重启、OAuth授权和工具调用。对Quick检查运行地址更新、停止后不可复制旧地址。错误Token、错误源站端口和失效证书应显示失败，不应误报公网可用。

如出现问题，保留版本号、操作步骤与脱敏日志；不要附带Token、私钥或配置明文。
