- [ ] 1.2 Cloudflare与共享身份收敛（FR-3、FR-4）。证据块：读cloudflare.rs、PublicOrigin、listener与路由锁；复验metrics/EOF/连接乱序、超时、代际隔离、失败rollback和本地HTTP身份联调；公网认证另计。
- [ ] 1.3 配置迁移与并发安全（FR-5）。证据块：读migrate/store/配置锁，复验损坏/未来版本/冲突/回滚/锁超时；兄弟模块可见性回归尚未提交，不计通过。
- [ ] 1.4 系统凭据保护（FR-6）。证据块：确认JSON明文现状；实现平台安全存储后需clean-target迁移、重启与canary扫描、失败不降级测试，未完成即HIGH阻断。
- [ ] 1.5 界面交付（FR-7）。证据块：核对TunnelConfigForm与workspace页面未提交差异；发布前需正常受审写入、最终SHA回读、Svelte构建和实际MCP/Actions复制场景；平台拒绝不得绕过。
- [ ] 1.6 Rust与前端完整基线（FR-8）。证据块：本次新增发布候选验证v4，真实执行all-targets/check、locked/test、-D warnings；Linux bytes_to_mb候选被写入拦截。对应源码最终CI结果而不是旧绿灯决定完成。
- [ ] 1.7 实机公网验收（FR-9）。证据块：真实FRPS、Named/Quick、DNS、TLS、ChatGPT授权和重启、断网恢复；每项环境/步骤/响应/日志摘要/时间/版本，缺条件保持BLOCKED。

- [ ] 1.9 原版规格校验（FR-11）。证据块：原版4.0.1中文名拒绝、ASCII目录缺三文档复现；字节一致映射后原版通过，缺FR/SHALL/覆盖矩阵等反例失败。仅结构完整性，不代表本清单全部完成。
- [ ] 1.10 逐轮与最终收敛（FR-12）。证据块：每轮diff/review/分数/修复记录，最终检查spec、UI、安全、实机、版本、构建门；存储被阻断操作及剩余差异，不发布虚假PASS。
