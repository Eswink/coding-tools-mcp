## 本轮已经写入源码的功能

### FRP 配置和公网地址

新增共用的 `FrpRouteOptions`，分别接入 MCP 和 Actions，使用有默认值的嵌套 `frp` 字段读取旧配置。没有修改工作区 ID、OAuth client ID 或签名密钥的生成规则。

工作区隧道表单可编辑服务器 IP/主机名、控制端口、完整自定义域名、传统子域名前缀与独立后缀、公网 HTTPS 端口、HTTP/HTTPS、本地目标、压缩、TCP 多路复用及 frpc↔frps TLS。连接参数目前位于工作区高级配置；同一工作区共用 frpc 的 MCP/Actions 参数必须兼容。

`serverAddr` 与公网路由域名分离。自定义模式生成 `customDomains`，不再强制填写子域名前缀。传统模式优先使用独立后缀；仅对旧的有效 DNS 服务器名称保留后缀回退，拒绝把 IPv4/IPv6 拼成域名。Rust 端的 FRP URL、工作区端点与 Actions URL 派生共用解析器；前端采用对应的纯函数，并有独立回归测试。

### HTTPS 和生成配置

HTTP 模式表示公网 HTTPS 在服务器反向代理等外部入口终止；应用不会自动配置该代理、证书或 DNS。HTTPS 模式明确区分已有本地 TLS 服务和 `https2http` 插件：前者必须显式指定目标端口并拒绝明显指向内置普通 HTTP 端口的配置，后者要求证书/私钥路径。

实际 Rust TOML 生成器已接入新字段和字符串转义，保留 `loginFailExit=false` 及已有心跳配置。前端提供不含真实 Token 的 TOML 预览；预览名称是示例名称，实际代理名仍使用稳定的工作区标识。

新增启动前 `frpc verify -c` 校验路径：候选配置验证完成后才替换当前 FRP 路由；验证副本用无效占位 Token，**只做配置结构检查，不代表 Token 认证通过**。证书/私钥要求为本机可读的绝对文件路径。临时文件使用独立名称并清理，Unix 权限 0600；校验超时会终止校验进程。

### 冲突与回滚

路由冲突按规范化的服务器连接地址、控制端口、代理类型及完整路由主机名检测，而非仅比较子域名前缀。配置指纹、MCP/Actions 参数比较和 Actions 配置回滚包含新 `frp` 字段。

FRP→FRP 重配不再先停止旧隧道再校验新配置；恢复活动路由时不再用尚未验证的表单配置覆盖运行中的路由快照。保留既有断网恢复、防抖及重连逻辑，不改工具执行、文件、Git、历史会话内核。

### Cloudflare 固定入口

界面区分“固定域名（Named，长期使用）”与“临时域名（Quick，重启变化）”，提示在 Cloudflare 侧把整个固定主机名映射到本工作区实际 HTTP 端口；只填写本应用 URL 不会自动创建 DNS 或远端路由。Named 校验拒绝 trycloudflare.com 临时地址、IP、路径、凭据、查询和片段，规范化大小写、尾点和默认端口。

Named 启动改用 `TUNNEL_TOKEN` 子进程环境变量，不把 Token 放入 argv，并对读取到的日志做该 Token 值的替换脱敏。环境变量仍可能被同一操作系统用户读取，**不是加密凭据存储**。

仅有 `starting metrics server`、日志打开失败或 EOF 不再产生就绪成功；Named 需要实际连接日志，Quick 需要连接日志和临时地址两个信号。启动异常/超时清理子进程及日志任务；并发读取 stdout/stderr，避免一个输出流阻塞另一个。这里的 ready 表示隧道连接证据，不表示 DNS、TLS、源站和 OAuth 全部健康。
