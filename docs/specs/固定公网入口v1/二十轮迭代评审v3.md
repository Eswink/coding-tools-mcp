## 已提交的主要改造

1. 每次listener启动创建独立代际的共享PublicOrigin，MCP元数据、OAuth Token校验、Actions认证和OpenAPI servers读取同一身份。旧操作持有旧代际句柄，不会覆盖新listener身份；尚未取得地址时，不通过不可信Host头生成公网issuer。
2. 自动和手动隧道操作在路由锁内发布地址，Quick临时地址不再作为固定配置写入磁盘。停止和替换失败按实际可见线路清理或恢复身份，不放宽issuer/audience校验。
3. 拒绝损坏JSON、数组、null和未来版本配置；清理旧Quick缓存而保留Named域名与签名密钥。同目录临时文件、sync、原子替换和失败清理避免先删旧配置。
4. DataStore保存失败回滚内存；三方合并无关并发字段，拒绝同字段冲突、删除与密钥旋转冲突以及数组并发冲突。
5. 稳定旁路profiles.lock与进程内互斥组合，跨进程合作式排他、限时等待，释放时不删除锁文件。锁不是加密，也不能阻止不遵守协议的外部编辑器。
6. 新增36项Rust测试源码，包括4项实际本地HTTP联调和子进程文件锁争用；入口Node回归从43项增加到47项。
