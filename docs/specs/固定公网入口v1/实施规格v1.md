# 固定公网入口实施规格 v1

## 状态与边界

- 需求来源：用户确认的《仓库分析与穿透改造方案v1》。
- 源码基线：`d0b5313ec39ea108f35dcc0773a2c6ba6d147e28`（0.2.1）。
- 工作分支：`feat/固定公网入口v1`，目标分支 `main`。
- 当前阶段：执行环境预检。本文是待实施规格，不表示功能已经完成。
- 本分支不自动合并、不发布版本、不修改真实 DNS、FRPS、Cloudflare 账户或工作区凭据。
- 示例仅使用 `203.0.113.10`、`mcp.example.com` 等保留示例值；截图中的真实 Token 不进入代码、日志或文档。

## 目标

1. FRP 支持服务器 IPv4/IPv6/主机名与完整自定义域名分别填写，不再生成“子域名.IP”。
2. 可视化编辑域名模式、HTTP/HTTPS 转发、压缩、TCP 多路复用和必要的 TLS 参数；设置真实进入 frpc 配置。
3. Cloudflare 复用已有 Named Tunnel，固定公网入口；Quick 明确标注临时测试用途。
4. 公网地址的配置、运行时发现、展示、MCP/Actions/OAuth 使用保持一致；重启不无意改变固定地址或签名身份。

## 不变量

- `serverAddr` 只用于 frpc 连接 frps，不作为自定义域名的后缀。
- 公网配置保存 origin，不保存 `/mcp`、query、fragment 或 userinfo；端点由后端唯一解析器追加。
- 自定义域名模式不能要求子域名前缀；传统模式使用独立后缀，兼容旧的有效配置。
- `transport.tls.enable`（frpc↔frps）不等于公网 HTTPS。
- 本项目内置 MCP 是普通 HTTP listener，不能把 `type=https` 直接指向它并声称 TLS 可用。
- 固定域名不能通过 Quick Tunnel 缓存、HTTP/2 开关或放宽 OAuth issuer/audience 校验获得。
- 进程存活、隧道连接、源站可达、OAuth 可用是不同状态；不能用 metrics 启动日志判定公网成功。
- 正常重启保持 client ID、签名密钥和固定 canonical origin；过期或撤销 Token 仍可要求重新授权。

## P1：公网地址模型与迁移

### 实施

- 分离服务器连接地址、代理匹配主机名、固定公网 origin、临时运行时发现地址。
- 统一 `frp_public_url`、`computed_public_url`、MCP/Actions 端点与 OAuth metadata 的解析来源。
- 固定地址只接受 HTTPS origin；规范大小写、尾斜杠、默认端口；拒绝路径、userinfo、query、fragment。
- 旧 FRP 子域名配置迁移后行为不变；服务器 IP 不得回退为 DNS 后缀。
- 旧 Quick URL 不能成为下一次 listener 的固定 issuer；过期地址只可作为明确标记的历史信息。
- 增补数据 schema 版本/默认值、往返序列化及失败回滚；损坏配置不得静默变成空工作区并覆盖原文件。

### 影响面（静态识别，非已完成的 GitNexus impact）

`workspace/model.rs` → `tunnel/frp/mod.rs`、`tunnel/supervisor.rs`、`runtime/supervisor.rs`、`commands/runtime.rs`、`commands/tunnel.rs` → `mcp/listener.rs`、`actions/listener.rs`、`auth/oauth.rs`。

风险：高。地址变化关联 OAuth issuer/audience 及现有授权，修改前需执行符号级 impact；不得降低认证校验规避迁移问题。

## P2：FRP 图形配置与生成

### 服务器连接配置

- 服务器地址：IPv4、IPv6 或主机名，不带协议、路径和控制端口。
- 控制端口：整数 1–65535，默认 7000。
- Token：保留、更新、清除语义明确；预览/导出脱敏。
- TCP 多路复用、连接 TLS；必须进入连接配置指纹和共享 frpc 兼容性检查。
- 传统子域名后缀独立配置，对应 FRPS 的 `subDomainHost`。

### 工作区路由

- 域名模式：完整自定义域名 / 子域名与后缀。
- 第一版至少支持单一完整域名，并选定唯一 canonical origin。
- 本地目标默认跟随实际 MCP/Actions 端口。
- HTTP：服务器 HTTPS 反向代理终止 TLS，再转到 FRPS HTTP 入口。
- HTTPS：明确选择已有本地 TLS 服务，或者 https2http 插件并提供证书/私钥路径。
- 压缩参数进入代理配置；TLS 不可由端口号猜测。
- 脱敏 TOML 预览；使用可转义的结构化生成方式，禁止未转义字符串拼接。
- 应用前执行真实 `frpc verify -c`；随后单独做连接和公网检查。
- 更新资源冲突检测、配置变更比较、重启和回滚，覆盖 MCP 与 Actions 共用/独立服务。

### 文件范围

`settings/*`、`workspace/model.rs`、`workspace/resources.rs`、`commands/frp_profiles.rs`、`tunnel/frp/*`、`tunnel/supervisor.rs`、`src/lib/api/settings.ts`、`src/lib/types/*`、`TunnelConfigForm.svelte`、`src/routes/settings/frp/+page.svelte`、`src/routes/workspace/[id]/+page.svelte`。

保留现有恢复/防抖逻辑；不顺手重写工具执行、文件操作、Git 或历史会话内核。

## P3：Cloudflare 固定入口与生命周期

### 体验

- Named：显示“固定域名（长期接入，推荐）”。
- Quick：显示“临时域名（重启会变化）”，不能把编辑展示地址暗示为绑定成功。
- Named 需要 Tunnel Token 和固定 HTTPS origin；拒绝 trycloudflare.com 临时域名。
- 提示远端 Published application route 的 Service URL 必须匹配本地实际端口，不能只填写本应用公网 URL。
- 明确需要转发该主机名下的 MCP、OAuth、well-known 路径，而不仅是 `/mcp`。
- 首次从 Quick 迁移到 Named 可需要一次重新配置/授权，不承诺已有授权自动跨域迁移。

### 可靠性

- Named 就绪必须有有效的隧道连接证据；`starting metrics server` 和输出流 EOF 不得产生 ready。
- 区分模式相关超时、认证、DNS/TLS、源站连接和 metadata 错误。
- 启动超时/异常时终止并等待子进程，清理日志读取任务，避免孤儿 connector。
- Token 避免放入 argv；采用环境变量或受限 Token 文件时说明各自安全边界，并检测二进制能力。
- 对 Quick 的新地址执行 listener/OAuth 同步或受控 listener-only 重启，不能因地址同步再次重建 Quick Tunnel。
- 失败不得覆盖上一个有效固定 origin；切换 provider 不得保留错误的旧路由/进程。

## P4：验证矩阵

| 场景 | 必须验证的结果 |
|---|---|
| FRP 服务器 IPv4 + 独立域名 | serverAddr 保持 IP，customDomains 正确，公网 origin 不含拼接的 IP 后缀 |
| IPv6 服务器 | 连接地址按 FRP 格式生成，不被当作公网域名 |
| 旧子域名配置 | 迁移前后有效端点相同，无无意授权重置 |
| 用户填入 URL 路径/凭据/非法端口 | 后端拒绝；不得绕过前端校验 |
| Token 含引号/反斜杠 | 配置可解析，预览、错误、导出不泄漏凭据 |
| HTTP + 服务器 TLS | 公网证书、Host 路由、OAuth 路由完整可达 |
| HTTPS 透传/https2http | 真正 TLS 握手通过，不能仅检查 frpc 进程 |
| 重复域名/共用连接配置冲突 | 正确阻断，不破坏已有可用线路 |
| 保存失败、verify 失败、启动失败 | 原配置/原线路仍可恢复，不出现半保存状态 |
| Named 多次重启 | hostname、issuer、client ID、签名密钥不变；未过期 Token 继续符合校验 |
| Named 仅输出 metrics/直接 EOF | 不得成功；子进程已回收 |
| Named 错误 Token/端口/DNS/证书 | 错误分层，无“本地进程活着即公网成功” |
| Quick 新地址 | UI、运行时、metadata 同步；旧地址不继续充当固定 issuer |
| MCP/Actions 并行与断网恢复 | 服务隔离、路由完整、无无意重复重启或孤儿进程 |

基础检查：`npm ci`、`npm run check`、`npm run build`、`cargo check --locked --manifest-path src-tauri/Cargo.toml`、`cargo test --locked --manifest-path src-tauri/Cargo.toml`。必须标明基线失败与本次回归的区别。

以上自动检查不替代真实 FRPS、Cloudflare、DNS、TLS 或 ChatGPT 联调。缺少账户/部署环境时记录 BLOCKED，不填写 PASS。
