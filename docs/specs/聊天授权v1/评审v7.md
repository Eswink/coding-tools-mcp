## 本轮问题与修改
原令牌表单要求 client_id 必须存在，使标准 Basic-only 客户端提前被拒绝；旧解析会混用表单身份和 Basic secret，且格式错误的头可能回退表单。按照 RFC 6749 2.3.1/3.2.1，允许单一认证方式，重复身份必须一致，拒绝双重认证、重复头、非 Basic 头、无效 Base64/百分号/UTF-8、控制字符与超长字段。Basic 组件按表单编码解码，认证失败返回统一 401 挑战且不缓存；不改变 PKCE、resource/issuer、期限、授权码一次性消费或聊天授权策略。

新增六组 Rust 回归：Basic-only 缺表单身份、post/公共 PKCE 兼容、混合/冲突/错误头及授权码保留、编码与大小写、恶意格式与边界、八线程授权码竞争只有一个成功。测试凭据是本地静态夹具，不用于真实账户或网络服务。
