# 聊天授权评审 v18：原生候选证据严格门禁

## 范围

## 门槛

必须有正确且有序的八组名称，每组 passed 必须为布尔 true；不再仅依赖 tests.Count。同时绑定精确源码 SHA、GitHub run_id、版本、包类型、debug/release 区别和重新读取实际被测二进制的 SHA-256。必须观察到原生 WebView、IPC、OAuth，且清理成功；包含失败元数据、错误布尔类型、重复 JSON 键、非有限数、超大/非对象报告均拒绝。旧报告没有 run_id/清理观察值时不能充当新门禁的验收证据。

合成元数据的矩阵报告必须保留 synthetic_conversation_metadata=true、real_chatgpt_verified=false；检查器只能输出 native candidate evidence，publish_approved 永远为 false。它不是签名证明，不证明真实 ChatGPT 请求来源，也不代替审核、双平台全量基线、可信公网入口验证或公开附件复核。
