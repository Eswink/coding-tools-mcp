## 本轮内容
只新增测试脚本、CI 和本记录，不更改产品逻辑或版本。CI 从同一源码构建带真实静态前端的 Ubuntu debug 程序（非安装包，非 Release），用固定 tauri-driver 2.0.6 和真实 WebKit 在 Ubuntu 22.04/24.04 执行八组验收：
1. 真实窗口和本机安全配置。
2. 真正 OAuth metadata、PKCE 码交换和 401 挑战，不签发假 token、不访问真实 ChatGPT 回调。
3. 未审批/缺上下文/模型参数伪造拒绝。
4. 原生点击批准 A，A 可读文件而 B 仍被拒绝。
5. 两聊天真实 Python 子进程、异步 job 查询/取消隔离、同幂等键独立、本机 IPC 取消。
6. 原生撤销、只读授权及禁止权限自升级。
7. 原生独占切换、最后批准者唯一获准、拒绝 C。
8. 真正重启应用，安全存储保留 OAuth 但授权不恢复。

审批、拒绝、撤销和独占必须用 WebDriver 点击，不注入批准 IPC。Setup/本地任务管理允许真实 Tauri IPC，不替代授权按钮。所有 HTTP 变更只发一次；只读状态有界轮询。复用已验收的 Xvfb→D-Bus 启动、Portal 激活和原生直连传输，不关闭 WebKit 沙箱。
