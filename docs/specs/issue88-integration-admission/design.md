## 技术方案与 API 设计
### Fixed production boundary (FR-1, FR-4, FR-5)
The new admission module receives only the owning exact concrete wire.GitHub instance, its identical frozen Selection and an operation-owned deadline/cancellation callback. No subclass, custom get function, caller verifier, bool, decoded report or receipt import is admitted as authority. Existing _authenticate keeps its tuple-or-raise interface, calls the fixed verifier and checks complete admission; remaining missing gates always raise fence_blocked today. No cached/retained report, new permit or session property is added.
Actual session activation runs authentic GETs before staging. ObserveFence/ObserveDraft/VerifyPublished and the direct mutation sink repeat the same fixed path; the latter remains before before_write/sendall. Existing remote constraint, owner authorization and typed latest-absence source remain blocked. Latest404 checks unavailable typed absence before any new authenticated admission reads, retaining tokenless verification boundaries.
### Source and workflow (FR-1)
Read the fixed repository, exact selected heads/tags ref, selected git commit and three nonrecursive trees (source root, .github, workflows). Require exact returned SHA, nontruncated bounded unique entries and040000 tree/100644 dot-rc-integration.yml blob modes. Bind that blob to the selected invocation; do not reinterpret workflow text as authority. Require active workflow metadata with exact fixed path/ID. Push supports branches; workflow_dispatch supports branch/lightweight-tag refs; PR merge refs stay unsupported. This does not satisfy the separate postmerge-invocation gate.
### Run/attempt/jobs and fences (FR-2)
Reuse release_tag_gate.successful_run/latest_run/paginate and rc_consumer_snapshot._ObservedAPI/_strict_run plus rc_publication_stage._bind. The highest exact-source run ID across every status must be the frozen selected run, with current selected attempt. Exact seven names are native (ubuntu-22.04), native (ubuntu-24.04), native (windows-2025), real-transport (ubuntu-22.04), real-transport (ubuntu-24.04), browser and oauth-process-browser. Every job is completed/success and bound to run/attempt/head/time/unique ID. No FINAL or artifact reads are needed.
Observe source, strict successful run/jobs and explicit attempt; repeat the run/jobs/attempt snapshot; reselect newest and reread current run; repeat source. Require equality throughout and final active/deadline check. Paginate complete counted results, reject duplicate IDs/count drift/short pages/1000-result cap and unsupported newer runs. Reobservation is non-atomic and cannot claim universal freshness.
### Canonical digest and data model (FR-3, FR-4)
The private frozen report contains selected subject and one authenticated integration digest. Derived ordered rows give full_integration/current_admission/passed, every other gate unknown, and tag_absence its historical_pretag phase. Global status is blocked; approvals and snapshot_atomic are false; draft visibility is unknown. It is inert data and no production entry consumes a caller-created report.
Hash UTF-8 JSON without trailing newline, sorted keys, compact separators, ASCII escapes and no NaN. Envelope fields are schema=rc-full-integration-v1, gate_id, selected SourceIdentity, selected InvocationIdentity, the exact live source/ref/commit/tree/workflow projection and strict workflow/run/jobs evidence sorted by job ID. Project run repository fields to id/full_name. Exclude tokens, raw bodies, actor PII, unrelated API metadata, wall-clock receipt time and gate_evidence itself. Match the selected gate digest exactly; source version is only bound as an expectation, not independently approved here.
### Deadline and interruption (FR-5)
Thread one deadline and active callback through metadata/get/_request and helper GET adapters. Explicit None handling must preserve deadline0 as expired. Check before connection, sends/receives, pages/passes, after parsing and before return. Preserve cancelled/timeout through reused ValueError-sanitizing helpers with a private two-code interruption carrier. Synchronous DNS/kernel delays cannot be forcibly bounded; late completion must fail closed. Other errors remain sanitized and cannot manufacture a report.

## 设计决策与风险
Keep legacy eligibility/evaluate byte-identical because caller reports remain untrusted; authentic I/O belongs to the fixed publisher boundary. Implement the real session read path now and update its old assertion explicitly rather than claiming an unexecuted verifier. CRITICAL dispatch and authentication changes require focused independent source/inverse review. FTS-unavailable graph limits remain disclosed. No live release, remote protection, credential, native Windows or held snapshot/PR98 changes are included.
