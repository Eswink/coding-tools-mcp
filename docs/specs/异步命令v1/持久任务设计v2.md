# 异步命令第二阶段：持久记录、受管进程与桌面查询

## 接受范围

提交、查询、取消仍为普通 MCP/Actions 工具，不声明原生 Tasks 扩展。执行与 HTTP 生命周期分离。当前任务列表及终态日志支持同一系统用户、工作区配置和服务通道恢复；MCP 与 Actions 不共享权限空间。

1. 提交必须先保存加密的 request_id、指纹、job_id 和 queued 记录再启动命令；同键不同参数拒绝，不静默重复执行。
2. 使用已有 AES-GCM/系统凭据库，记录放于应用 Harness 目录，不放项目目录。不新增明文命令或日志文件。损坏、缺密钥、未来版本拒绝加载并保留原文件。
3. 一个服务命名空间由跨进程文件锁独占；进程内相同服务重建复用受管任务。应用退出后不承诺命令继续；重新加载非终态记录为 interrupted，保留未知状态与幂等键，绝不按陈旧 PID 接管/杀进程或自动重跑。
4. 取消/超时作用于受管进程组或 Windows Job Object；Windows 在恢复主线程前加入 Job；附加失败拒绝运行。自行逃逸组/提权等不属于安全沙箱保证。
5. 普通 exec_command 仍上限十分钟；异步默认十分钟，可由工作区配置允许最长24小时。请求 timeout_ms 是执行预算，不是 HTTP 等待。预算不能通过伪造参数扩大普通工具权限。
6. 输出每流1MiB环形缓冲、绝对字节游标和丢弃计数维持；约2秒和终态加密快照。崩溃可能丢失最后未落盘输出，明确标记 interrupted/output_complete=false。
7. 每通道4活动/32保留、终态1小时，未知终止不自动过期。仅明确人工核查确认终止后可释放 interrupted 的占用；仍保留去重键到保留期结束。
8. 桌面工作区提供任务列表/状态/增量日志/取消；轮询不重叠、切换工作区不串结果、不自动唤醒GPT。

## 验证与回退

保留原200ms真实执行截止和非阻塞提交/取消断言；功能测试给予可解释的Windows启动预算。增加加密落盘/重启终态/未知恢复/损坏保护/通道隔离、长预算隔离、子孙进程清理、传输断连与前端检查。两平台all-targets、完整test、生产库-D warnings不可降级。v0.2.3与main不自动改动；本阶段在PR#2完整提交，通过后再决定合并与发布。
